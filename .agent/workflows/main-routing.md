# 项目任务路由

先遵守当前用户授权和 AGENTS.md，再加载环境已有的 encoding-guard、pua、chinese-comments、code-comment-style；修改代码前加载 code-boundaries 和 code-placement。技能缺失时说明，并继续可执行工作，不假称已加载。

- 复杂问题、失败或自动化变更：`.agent/skills/self-improvement/SKILL.md`。
- 真实 IDE、审批、输入、窗口接管、资源采样：`.agent/skills/native-desktop-acceptance/SKILL.md`。
- 运行版本发布和三渠道原包比较：`.agent/skills/three-channel-publication/SKILL.md`。
- 故障定位先读原失败和源码，再作单变量对照；修复遵循当前目标要求的 issue、红绿回归、PR/CI、审查、合并和发布流程。
- 纯文档任务不启动无关桌面测试，不为维护文字发新版本。历史 evidence 链接见 `.agent/skills/self-improvement/references/lessons.md` 索引与 `docs/verification-*`。

每次说明实际加载的技能；路由只选择工作方法，不扩展权限或替代用户验收条件。
