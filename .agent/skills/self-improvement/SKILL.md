# 项目经验维护

先读 `references/lessons.md` 的有效规则索引，按当前任务转到原生桌面验收或三渠道发布技能。历史流水在索引链接的 verification 归档中，只按需要检索。

出现新坑时先保留最小失败证据、真实原因或不确定性；复用已覆盖规则，只有新事实才补充对应技能或索引。run ID、原始堆栈、资产摘要和哈希放 verification 文档或本轮测试根目录，不重新堆满本索引。

备份、编码、Git 状态、源码边界和现有授权按用户要求执行；本技能不授权额外发布、凭据、权限或删除操作。结论注明已读源码、已跑验证或推测。
