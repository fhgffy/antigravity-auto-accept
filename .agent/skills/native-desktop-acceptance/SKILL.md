# 原生桌面验收

用于修改扫描路径、审批识别、输入保护、所有权或生命周期后的真实验收。纯文档修改无需启动桌面。以下路径和命令按仓库根目录执行。

## 测试边界

- 使用 F 盘本轮独占目录、独立 IDE 配置和扩展目录，先冻结源码与原包 SHA。登记根 PID、父 PID、创建时间、可执行路径、配置目录和 HWND。
- 动作、采样和收尾都重新核对身份；句柄消失或 PID 退出先退休旧记录，再登记新实例。不能拼接不同进程的内存曲线或重启前后的时长。
- 不修改用户 IDE 安装、信任或审批设置，不操作未登记窗口及未保存内容。只读观察失败不等于产品退出。
- Chrome 仅使用自己启动的独立配置、CDP 和回环页；不通过 Computer Use 操作 Chrome，不接管用户浏览器。

## 执行顺序

1. 读取当前验收需求与 `.agent/skills/self-improvement/references/lessons.md` 索引，检查 Git 状态；对故障先记录原始失败。
2. 使用正式包建立基线；带长会话、空闲和最小化窗口分别记录 UIA 元素数、窗口状态和源版本。
3. 每张真实卡记录窗口身份、完整 RuntimeId、精确目标的 UTF-8 SHA、出现时间范围及唯一成功事件；通用 Submit 文案不能证明目标归属。
4. 修改后跑完整回归与 VSIX 字节校验，再跑需要的原生单窗、多任务、双向接管、最小化、待批 Stop/Restart/关闭重开和输入场景。
5. 长测使用单调时钟与独立只读采样器，按 PID/创建时间计算单核 CPU、私有内存斜率、句柄及子进程。说明预热、刷新、缺样和观测时段；GC 堆平稳不代表私有内存平稳。
6. 审批延迟的起点由扫描器之外的观察器取得，保留最后阴性/首次阳性时间及查询间隙，不能使用扫描器首次发现时间代替卡片出现时间。
7. 正常关闭登记的测试窗口，核对确切后代退出；先按原字节归档扩展日志，再按真实路径白名单清理本轮配置。报告实际清理方式，不把回收站当作空间已释放。

## 命令和方法

在独占工作区执行项目已有入口，完整输出保存到本轮测试根目录：

```powershell
npm test
npm run package
$manifest = Get-Content package.json -Raw | ConvertFrom-Json
& ./tests/validate-vsix.ps1 -VsixPath "$($manifest.name)-$($manifest.version).vsix"
```

Windows PowerShell 5.1 读取含中文的无 BOM 脚本时，使用项目现有 UTF-8/AST 引导，不依赖默认 ANSI 解码；记录实际引擎版本。显式调用所需 `powershell.exe`/`pwsh.exe`，不能仅凭工具的 shell 参数认定引擎。

每次动作前取得新 UIA 树，按已观察控件身份定位；不要从 RuntimeId 的某个整数猜 HWND。最小化 Chromium 的树可能收缩或保留旧状态，结合恢复后的新树、真实截图及 READY/退出日志判断所有者。

## 已遇到的坑

- PrintWindow 可能返回空白图片；文件存在、模型回复标记及 Agent response 都不能冒充工具原始 stdout。
- Chromium ValuePattern 可保留已删草稿，必须结合 TextPattern/截图；仅能清除与本轮发送文本完全相同的草稿。
- 两个真实窗口的 WAITING/ON 要以新树、互斥与生命周期日志交叉核对，不能由旧状态栏文字断定双 owner。
- CacheRequest 的 RawView 与原查询可返回不同集合，实测会多出 Restore；性能比较先对齐视图、目标集合和属性读取数量。
- 缓存仅用于发现候选；动作前仍要取得 live 元素并复核 RuntimeId、目标、宿主、输入和前台。缓存变快不等于审批语义等价。
- 系统输入动作只能用登记测试窗口；普通键、鼠标、修饰键、遮挡与切窗边界不得通过放宽阈值让回归变绿。
- 比较性能时固定窗口布局和并行观察器；整轮耗时减半不代表扫描器 CPU 减半。探针若每轮用 Process.Refresh 读取自身私有内存，会把全系统进程信息查询算进自身 CPU；先测空操作开销，再用原生当前进程计数或外部采样拆分。
- 状态记录来自 CIM CreationDate 时，用同一 API 回读创建身份；.NET Process.StartTime 的精度不同，不能逐 tick 混比后误报进程被替换，也不能因此放宽身份检查。
- Chromium 可把工具结果也展平到 Agent response 父节点。应由实际工具步骤展开后出现的命令/原始输出及截图共同判断；单看父节点名称或模型复述均不足。
- 将初始化移到互斥接管之后，必须同时检查宿主协议和启动截止时间；WAITING 免超时仅适用于等锁，拿锁后的重型初始化仍需有界恢复。用真实宿主入口覆盖分段/重复协议、READY、停止卸载和旧实例事件。
- 初始化块跨多个函数时，移动闭括号后立即解析完整 AST，并用冷等待回归确认 UIA 和审批函数均在拿到锁后初始化；字符串锚点存在不证明作用域正确。

结论标记“已读源码 / 已跑验证 / 推测”，并写明哪些是本次实测、哪些是原版本证据复用、哪些仍未验证。历史证据见 `docs/verification-*`，不是当前环境的自动通行证。
